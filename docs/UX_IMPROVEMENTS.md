# 用户体验与交互设计优化规范

> **当前基线（2026-08-18）**：本文档记录前端 50+ 业务视图的交互优化成果，包括错误状态隔离、持久错误提示横幅、组件生命周期保护、样式解耦分层与暗色主题支持。

---

## 核心体验优化

### 1. 复合视图的子请求错误隔离
- **优化前**：复合页面（如商家销售、退款核销、GMV 驾驶舱）若其中一个次要接口（如辅助分布图）报错，会导致整个页面报错甚至白屏。
- **优化后**：将多个子模块的错误状态独立拆分（例如 `kpiError`、`trendError`、`rankingError`），单项失败仅在对应区域显示 `ErrorAlert` 并保留重试按钮，其余正常区域依然完整渲染。

### 2. 异步生命周期与迟到响应丢弃 (`isActive`)
- **优化前**：用户在抽屉或弹窗关闭后，若先前的异步请求才返回，可能错误触发 Toast 提示或回写已销毁视图。
- **优化后**：统一引入 `isActive` 作用域活性门与请求代际比对，组件卸载或操作取消后主动丢弃迟到响应，杜绝幽灵弹窗与内存泄漏。

### 3. 表格骨架屏与流畅过渡
- 全站核心表格与图表面板配备 `TableSkeleton.vue`，在数据加载中展示流光动画骨架，告别生硬的全局 Loading 遮罩。

### 4. 样式解耦分层与暗色主题
- **组件样式抽取**：大型组件的 CSS 抽取至 `apps/web/src/styles/components/`（如 `apple-button.css`、`gmv-kpi-row.css`）。
- **视图样式抽取**：复杂页面的 CSS 抽取至 `apps/web/src/styles/views/`（如 `order-center.css`、`user-center.css`、`merchant-sales.css`）。
- **主题适配**：全面支持浅色与暗色模式平滑切换（`styles/dark-theme.css`）。

### 5. 复制操作安全降级与反馈
- 封装统一剪贴板工具，优先使用 `navigator.clipboard`，在非安全上下文（如未配置 HTTPS 的 IP 访问）下自动降级至 textarea 兼容模式，并提供明确的成功/失败视觉反馈。
